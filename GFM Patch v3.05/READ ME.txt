This submod is meant to be used in conjunction with the unofficial patch of v.3.05 for Victoria 2.
You need to know how to use GFM alongside the patch for this to work here's the tutorial:

1. you install the patch in your mod folder.
2. Move your GFM and this submod to the mod folder inside the "Victoria 2 unofficial patch 3.05" folder
3. move the "start_patch_steam_version.bat" to your root folder (more specifically in the same folder where your v2game.exe is)
4. that bat file will create another v2game.exe and victoria2.exe inside the "Victoria 2 unofficial patch 3.05" folder
5. use the new launcher exe to use the patch version
6. then activate GFM with this submod (warning, do NOT activate any "patch" mod with this, as the patch is already there without any extra patch .mod
7. Enjoy

Link for the Unofficial patch: https://www.moddb.com/mods/victoria-2-unofficial-patch-305, https://www.nexusmods.com/victoria2/mods/26
