This submod is meant to be used in conjunction with the unofficial patch of v.3.05 for Victoria 2.
You need to know how to use GFM alongside the patch for this to work, here's the tutorial:

1. obviously, you download the patch, the links are: https://www.moddb.com/mods/victoria-2-unofficial-patch-305, https://www.nexusmods.com/victoria2/mods/26

2. Open the zip file and extract everything into your root game folder 
(in this case, "dinput8.dll" "dgVoodoo.config" and the "z_CreatineCore" folder are only necessary)

(ROOT FOLDER is where your v2game.exe is)

3. play GFM with the "GFM Patch v3.05" submod activated (you can play with another submod of your liking)

4. Enjoy

Note: If you aren't getting colonial factories, check the "creatinecore_settings.ini" in your "z_CreatineCore" folder
and check that your "LOCAL_MOD_CONFIG" value is set at 1
